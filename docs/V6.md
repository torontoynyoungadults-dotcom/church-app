## 2단계 — 성경 본문 자동 (개역개정 + NIV)
- `logic/bible6.js`: 개역개정 = 대한성서공회 성경 읽기 화면, NIV = BibleGateway 화면에서 필요한 절만 "절번호 본문" 줄로 뽑음 (소제목 · 각주 · 관주 제거, 두 줄로 나뉜 절 합침). 개역개정을 못 받으면 개역한글로 대신하고 알림. 6시간 기억.
- **주보 편집**: 본문 구절을 적으면 비어 있을 때 자동으로 채움 + "📖 본문 자동으로 채우기" 단추 (`bulletinFetchBible`).
- **오늘의 묵상**: 매일 자동 · 온라인 가져오기가 개역개정 + NIV 로. 한 칸에 `한글 줄 … [NIV] 영어 줄` 로 저장하고 묵상 화면이 같은 절끼리 짝지어 보여 줌. 관리 화면에 "📖 구절로 본문 채우기".

## 3단계 — 밝은 화면
- 베이지 · 사진 바탕 → **#F3F4F6 바탕 + 흰 카드 + 가는 선 + 진한 글씨(#0F172A)**, 주황은 강조에만(글씨용 #C2410C). 탭은 회색 트랙 위 흰 알약, 입력칸은 흰색 + 주황 초점 링. 포털 타일 아이콘 색도 밝은 화면용으로.
- **전환이 조금씩 번지던 원인**: 전환 순간 모든 칸에 color/background transition 을 걸었고, 글씨색 보정(가독성 지킴이)이 한가할 때 조금씩 돌았음 → transition 을 끄고 보정은 같은 순간에 한 번에, 지원하는 브라우저는 단추 자리에서 원이 퍼지는 **View Transition** 한 장면으로.

## 4단계 — 라이브 악보
- 위 막대 한 줄(56px, 예전 164px). ⏱ · 🎼 · 🥁 로 타이머 · 송폼 · 메트로놈 창 보이기/숨기기 (기억).
- **떠 있는 창** 4개 — 도구 · 메트로놈 · 송폼(곡 · 키 · BPM) · 예배 타이머. ⋮⋮ 손잡이로 어디든 옮기고 자리 기억(비율로 — 화면이 바뀌어도 같은 자리). 타이머는 "−" 로 작게(예배 경과만), 허브 아래 막대도 같음.
- 도구 창: ▴ 로 작은 알약으로 접기 · ⋯ 로 색 · 굵기 펼치기(컴퓨터는 처음부터 펼침). **이동 · 선택 모드에서 악보 빈 곳을 톡 → 도구 창이 접힘.**
- **자동 선택·이동**: 글자 · 코드 · 기호 · 송폼 라벨 · 펜 · 형광펜 · 지우개로 한 번 쓴 뒤 **빈 곳을 톡 → 선택·이동 도구로** (끌면 방금 쓴 것이 따라 움직이는 예전 동작은 그대로). 도구 · 기호를 다시 고르면 또 씀. 애플 펜슬로 톡은 점(스타카토)으로 남고, 펜슬 전용 모드에서는 손가락 톡이 전환.
- **메트로놈 따라가기 없앰** — 메트로놈은 기기마다 따로, 따라가기는 페이지만 ("함께" 탭 · 칩 정리).
- 폰 · 아이패드 세로(좁은 화면)는 예전처럼 서랍 메뉴 + 빠른 메트로놈 버튼 (타이머는 처음에 작게).

## 5단계 — 설문 · 투표 (각종 Form 관리)
- 만들기: "📝 신청서 / 📊 설문 · 투표" 고르기 + 본보기 6개(간단 투표 · 날짜 정하기 · 찬반 · 만족도 · 메뉴 · 우리 팀 설문).
- 설정: 🙈 익명 · ➕ 참여자 항목 추가 · 결과 공개(참여한 뒤 / 언제나 / 만든 사람만) · 다시 투표(=고치기) · 마감(닫는 날) · 참여 인원 공개.
- **대상**: 커미티 = 모두 · 역할(팀장들 · 셀장들 · 커미티 · 새가족팀 · 회계팀) · 팀 · 셀 · 선교팀 · 한 사람씩 섞어서. **팀장 = 우리 팀 · 우리 팀 사람만**(비우면 우리 팀). 대상이 아니면 포털에 안 보이고 열기 · 내기도 서버가 거절. 신청서에도 똑같이 쓸 수 있음.
- 참여자: Teva Apps 에 📊 타일 → 투표 → 바로 결과(막대 · % · 내 선택 ✓ · 익명이 아니면 고른 사람).
- 관리: 참여 현황(몇 / 몇 명 · 아직 안 한 분) · **🔔 아직 안 한 분께 다시 알림**(+이메일) · 익명이면 결과 · 엑셀에 이름 · 연락처 없음.
- API: `surveyResults` · `surveyRemind` · `surveyAudience` (나머지는 `_` 로 끝나 브라우저에서 못 부름). `logic/survey6.js`

## 알아 둘 점
- 대한성서공회 · BibleGateway 화면 구조는 여기서 진짜로 불러 볼 수 없어 **실제와 같은 모양의 가짜 화면**으로 시험했습니다. 배포 후 주보에서 구절 하나를 넣어 확인해 주세요. 두 사이트가 모양을 바꾸면 그때 한 번 맞춰야 하고, 그동안은 개역한글로 대신 채워지거나 "본문 열기"로 붙여 넣으시면 됩니다.
- 익명 설문도 "한 사람 한 번"을 위해 신청내역 시트에는 이름이 남습니다(화면 · 엑셀에서만 가림). 시트를 직접 여는 분은 볼 수 있습니다.
- 제미나이 다른 모델로 넘어가면 답의 품질이 조금 다를 수 있습니다(대부분 2.5 Flash).
