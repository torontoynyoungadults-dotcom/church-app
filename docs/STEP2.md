# Step 2 — 찬양·방송팀 허브 (연습 모드 · 실시간 필기 · 송폼 · 메트로놈 · 음정 · 가사 · 통계)

> 원칙: 이미 운영 중인 앱이므로 **기존 기능은 지우거나 바꾸지 않고**, 새 기능을 "덧붙이는" 방식으로 만들었습니다.
> 새 스크립트는 모두 `defer` 로 불러오므로, 어느 하나가 실패해도 예전 찬양 화면은 그대로 동작합니다.

**시험**: `scripts/test-step2-server.js` · `test-step2-client.js` · `test-step2-more.js` · `scripts/browser/*` (진짜 크롬 시험)

## 3. 기존 기능은 어떻게 보존되나
- 기존 API · 시트 · 열 이름은 그대로. 새 데이터는 **새 탭 `찬양주석`**(DB05 통합 문서)에만 저장 — 없으면 자동 생성.
- 곡 정보의 송폼은 기존과 같은 문자열(`V1-C-V2-C-B-C`)로 저장. 새 도구는 그 문자열을 만들어 줄 뿐입니다.
- 악보는 `/sheet/<Drive 파일 ID>` 로 스트리밍하되, **찬양악보 시트에 등록된 파일만** 열립니다(그 외 404).
- 권한: 소켓 접속 시 기존 토큰으로 인증(`찬양소켓인증_`). 필기 삭제는 본인 것만(편집 권한자는 전체).
- 예전 통계 팝업 코드는 그대로 두었고, 새 모듈이 없을 때만 예전 팝업으로 돌아갑니다(안전장치).

## 4. 배포
1. GitHub 에 올리기(`git push`) → Render 가 자동 배포(`npm install` 이 socket.io 를 설치).
2. Render 는 WebSocket 을 지원합니다. 추가 설정 없음. (Step 1 의 `scripts/db-setup.js` 수정본은 먼저 받아 두세요.)
3. 첫 실행 때 `찬양주석` 탭이 자동으로 만들어집니다.

## 5. 알아 둘 한계
- Render 무료 서버는 쉬었다 깨어나면 실시간 방 상태(리더 등)가 초기화됩니다. 팀 필기는 8초 안에 시트에 저장되고 종료 신호(SIGTERM) 때도 저장합니다.
- "나만 보기" 필기는 1.5초 뒤 서버(시트)에 저장되며, 계정 공유("팀 계정") 로그인이면 그 계정의 개인 필기는 함께 보입니다.
- 음성 큐는 브라우저 내장 음성을 씁니다. iPhone/iPad 는 무음 스위치가 켜져 있으면 소리가 안 납니다. 지연 보정은 기기별로 자동 측정.
- 가사 OCR 은 처음 쓸 때 라이브러리(tesseract.js)를 인터넷에서 받습니다.
- 리더 따라가기 스위치는 접속(세션)마다 기본 켜짐입니다.
- 구글 시트 쪽 코드는 가짜 구글(FakeGoogle)로 시험했고, 실제 구글 계정 연동은 배포 후 확인이 필요합니다.


## 7. 2차 보완 패치 (연습 효율 7가지) — 화면(프런트)만 바뀜
서버 시트 구조 · API · 열 이름은 그대로입니다. 서버는 `lib/realtime.js` 의 **허용 목록**(글꼴 3종 · 음표 도장 4개)만 늘렸습니다.

| # | 요청 | 어떻게 되나 (위치) |
|---|---|---|
| 1 | 쪽별 BPM · 송폼 연결 | PDF 쪽 → 곡을 자동 연결: 각 쪽 위쪽 40% 에서 곡 제목을 찾고(없으면 앞 쪽 곡이 이어짐), 쪽을 넘기면 곡 정보 · BPM · 송폼 버튼이 바뀜. 곡이 여러 쪽이거나 자동이 틀리면 위쪽 **"이 쪽의 곡" 드롭다운**에서 직접 지정(기기에 기억, "자동"으로 되돌리기 가능). `practice.js` (`resolveSong` · `scanTitles` · `syncSongForPage`) |
| 2 | 시작음 피아노 | 옛 피아노롤(목표 음 · 재생 · 마이크 · 점수)을 없애고 **가로 2옥타브 피아노 건반**으로 교체. **시작음 듣기**(곡 Key 의 으뜸음) · 옥타브 이동 · 도레미 표시 · 볼륨 · 건반 미끄러뜨리기. 소리는 Web Audio 로 배음 6개 + **ADSR 엔벨로프**(Attack/Decay/Sustain/Release) + 낮은 통과 필터 + 컴프레서. `pitch.js` |
| 3 | 유튜브 고급 조작 | 공식 **IFrame Player API** 로 교체. 속도 0.5 / 0.75 / 1 / 1.25 배, **A-B 구간 반복**(A 지정 → B 지정 → 반복 / 해제). API 를 못 불러오면 기본 임베드로 대신하고 안내. `ytplayer.js` (새 파일) |
| 4 | 단축키 | ←→ 쪽 · **↑↓ BPM ±1 (Shift 는 ±5)** · **Space 메트로놈 시작/멈춤**. 글자를 치는 중(글자칸 · textarea · 목록)에는 모두 꺼짐. 메트로놈 탭을 열지 않아도 동작. |
| 5 | 아이폰 · 아이패드 | 좁은 화면(폭 1100px 미만 태블릿 배치 · 900px 미만 컴퓨터 배치 · 높이 500px 미만)에서는 **🛠 메뉴 서랍** 하나에 확대 · 화면 배치 · 필기 도구 · 패널 열기를 모음. 닫혀 있는 것이 기본이라 악보를 가리지 않음. 바깥 누르기 · Esc · 메뉴 버튼 · (폰에서) 도구 고르기로 닫힘. 위쪽 바가 화면 밖으로 넘치던 문제도 해결. |
| 6 | 기본 확대 | 기본은 태블릿=한 쪽 전체 · 컴퓨터=가로 폭 맞춤(폰을 눕히면 가로 폭). **✂ 여백** (기본 켜짐): 쪽에서 글자 · 음표가 있는 부분을 찾아 그 부분이 화면을 채우도록 확대하고 스크롤을 그 위치에 맞춤. 종이를 자르지 않고 "확대 + 스크롤 위치"만 쓰므로 필기 좌표 · 팀 동기화는 그대로. |
| 7 | 필기 개선 | **나만 보기** 체크박스 하나로 교체(체크 안 함 = 팀 공유, 기본). "이 쪽" → **"현재 페이지"**. 색: 빨강 · 파랑 · 초록 · 보라 · 검정 · **흰색(수정액)**. 글자/코드 입력 중 **미리보기 색 = 고른 색**(치는 도중에 바꿔도 즉시 반영, 흰색은 칸 배경이 어두워짐). 글자 · 코드 · 기호에 **글꼴(고딕/명조/손글씨) · 크기 슬라이더**. **♩ ♪ ♯ ♭ 음표 도장**. |

**바뀐 파일**: `public/worship/practice.js` · `practice-panels.js` · `anno.js` · `pitch.js`(다시 씀) · `ytplayer.js`(새로) · `hub.css` · `views/Worship.html`(스크립트 1줄) · `lib/realtime.js`(허용 목록).
**보존**: 예전에 쓴 필기(주황 등 다른 색 · 글꼴 없음)는 그대로 그려짐 · 기존 필기 항목 형식은 그대로이고 새 항목만 `f`(글꼴)가 붙을 수 있음(옛 화면은 무시) · 리더-팔로워 쪽 넘김 · 저장 흐름 변경 없음.
**알아 둘 점**
- 팀에 연결되어 있지 않은데 "나만 보기"를 직접 고른 적이 없으면, 필기가 막히지 않도록 그 순간만 내 필기로 저장하고 알려 줍니다.
- 손글씨 글꼴은 기기에 있는 글꼴(iPhone/iPad: Bradley Hand · Noteworthy, Windows: Segoe Print)을 씁니다. 없으면 기본 필기체로 보입니다.
- 유튜브 API 는 처음 열 때 인터넷에서 받습니다(오프라인이면 기본 재생기).
- 시험: `npm run test:step2` (계산) + `npm run test:step2:browser` (진짜 크롬, 아이폰 크기 포함).
