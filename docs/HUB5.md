# HUB5 — 찬양·방송 허브 v5 (성능 · 팀사역 카드 · 설교 자막 · 오늘의 묵상 · 다른 분 화면 · 밝은 화면 · 기기별 배치)

> 요청서는 "GAS + Vanilla JS"라고 했지만, 실제 앱은 **Render(Node/Express) + 구글 시트**입니다(`server.js`, `logic/*.js`). 이 기준으로 고쳤습니다. 시트 · 열 · API 이름은 새로 만들지 않았고, 설정 시트에 `묵상자동`(켜기/끄기) 한 칸만 새로 씁니다(없으면 켜기).

## 0. 성능 — 무엇이 실제로 느렸나 (측정: `npm run perf:hub`, CPU 4배 느리게 = 아이패드 흉내)

| 원인 (찾은 것) | 고친 것 | 파일 |
|---|---|---|
| **가독성 지킴이**가 무엇이 바뀔 때마다 화면 **전체**(수백 칸)에 `getComputedStyle`을 다시 돌림. 연습 화면의 메트로놈 깜빡임 · 필기 · 알림처럼 1초에 여러 번 바뀌는 곳에서 계속 돌아 버벅임 | 바뀐 칸과 그 안쪽만 · 연습 화면(`.pv`) · 캔버스 · 가려진 허브는 건너뜀 · 10ms 조각으로 한가할 때 · 부모 바탕색 기억 | `views/Theme.html` |
| 연습 화면을 열 때 **뒤에 깔린 허브 전체를 다시 배치**(한 번에 0.5초, 4배 느린 CPU) | 연습 중에는 `body.pv-lock > .shell { content-visibility: hidden }` | `public/worship/hub.css` |
| 악보 위 막대 · 도크 · 패널의 `backdrop-filter: blur()` — 악보가 움직이거나 필기할 때마다 흐림을 다시 계산 | 연습 화면 안에서는 흐림 대신 거의 불투명한 어두운 유리색 + `will-change` 층. 허브의 붙어 다니는 "세션 시작" 막대도 | `hub.css` |
| 날짜를 바꿀 때 `scrollIntoView` 가 화면 전체 배치를 그 자리에서 강제 · 보이지 않는 아래 카드까지 모두 배치 | 주차 줄 가운데 맞춤은 다음 프레임에 한 번 · 아래쪽 카드는 `content-visibility: auto` | `views/Worship.html`, `hub.css` |
| 날짜 전환 | 받아 둔 주는 누른 표시가 먼저 그려진 **다음 프레임**에 교체 · 앞뒤 주를 한가할 때 미리 받기 · 같은 주 요청 하나로 합치기 · **LRU** 최근 14주만 기억 · 화면 모양의 **스켈레톤** | `Worship.html` (`loadWeek`, `prefetchAround`, `pruneWeeks`, `weekSkeleton`) |
| 세션/연습 첫 시작 | 허브가 한가할 때 **첫 악보 파일 + pdf.js** 미리 받기(`YNPractice.warm`) | `practice.js`, `Worship.html` |
| 휴대폰으로 찍은 큰 사진 악보(12MP = 비트맵 48MB, 5개까지 기억) | 긴 변 2800px 로 **한 번만 줄여서** 풂(`createImageBitmap` 크기 옵션 — 화면 밖 스레드, 안 되면 캔버스). 필기 좌표는 0~1 이라 그대로 | `practice.js` (`decodeScaled`, `prescale`) |

측정(4배 느린 CPU, 같은 자료): 날짜 전환 한 번에 화면을 붙잡는 시간 약 130ms → 약 75ms · 받아 둔 주 전환 9ms 안팎 · 세션/연습 시작 약 2.0초 → 약 1.1초 · 두 번째 시작 1.5초 → 0.8초.

**이미 되어 있던 것(그대로 둠)**: 메트로놈 박자는 원래 Web Worker, 오디오(AudioContext) · 음성(TTS)은 처음 누를 때 만들어짐, 필기는 rAF + 합쳐진 포인터 이벤트, 쪽 그림 저장소(LRU). 녹음기 · 시작음 · 화음 패널도 탭을 처음 열 때 만들어짐.

## 1. 사역팀 (`views/Team.html`)
- **팀 보고서** 탭의 "팀원 정보 보기" 목록 삭제 (팀원 상태 칸은 그대로).
- **팀원 관리**: 목록 하나 — 이름을 누르면 카드 펼침(연락처 · 이메일 · 생일 · 세례 · 제자훈련 · 선교팀 · 셀 출석, 역할 바꾸기 · 빼기), 다시 누르면 접힘. 아래에 따로 있던 "팀원 정보" 목록(같은 사람이 두 번 나옴)은 카드 안으로 합침. 정보는 팀마다 한 번만 불러 기억.
- 출석: `100% · 3/3` → **`셀 출석 100% (3/3회)`** (셀모임 · 관리 화면도 같게).
- 긴 이메일 · 이름이 잘리거나 겹치지 않게 줄바꿈. 예전 "소속 셀" 칸 중복도 정리.

## 2. 설교 · 묵상
- **자막**: 유튜브가 WEB 자막 주소에 재생 토큰을 요구해 서버에서 빈 자막이 오던 것이 주원인 → **안드로이드 클라이언트**를 먼저, 마지막에 자동 생성(asr) 자막 주소 직접. 그래도 없으면 **제미나이가 유튜브 영상을 직접 보고 요약**(공개 영상만, 소리 중심 · 낮은 화면 해상도). (`logic/app.js` 자막가져오기_, `logic/hub5.js`)
- 요약 버튼(`sermonMake`, `sermonGeminiSummary`)은 이제 **서버를 멈추지 않는 비동기**(`server.js`) — 영상 요약이 1~3분 걸려도 다른 사람 요청은 바로 처리. 매주 자동 요약도 자막이 없으면 영상으로 이어서.
- **오늘의 묵상 자동**: 매일 04:30 — 그날 확정된 말씀이 없으면 ① QT 시트 → ② 온라인 성경 읽기표(LectServe, JSON) → ③ 추천 구절 순으로 본문을 정하고 **개역한글(공개 번역, getBible)** 본문 + AI 해설 · 질문 · 적용 · 기도를 저장. 관리자가 먼저 정한 날은 건드리지 않음. 관리 화면에 "🌐 온라인 성경 읽기표에서 가져오기" 버튼과 켜기/끄기. 개역개정은 저작권 때문에 가져오지 않습니다.

## 3. 다른 분 화면 보기 · 새가족 알림
- 교인 · 새가족 모두 **그분이 로그인했을 때와 화소 단위로 같게**(시험으로 사진 비교). 안내는 화면 아래 떠 있는 띠로만, 버튼 모양은 그대로 두고 누르는 순간 막음("보기 전용" 안내). 새가족 화면은 위 버튼줄 · 로그아웃 줄까지 같게. 서버도 그분 로그인 응답의 나머지 값(`googleReady` 등)을 그대로.
- **김민솔 알림이 계속 뜨던 버그**: 알림 ID가 날짜마다 새로(`nf-new-오늘`)라서 치워도 다음 날 7일 동안 다시 떴음 + 새가족이 내용을 고칠 때마다 "화면에 붙어 있는" 푸시가 다시 감. → **읽지 않은 분만**(14일 이내 · 담당자 없음 · 교육 전 · 내가 확인 안 함), 치우면 그 알림의 분들을 사람마다 "확인함"으로 기록, 새 분이 오면 새 알림, 담당자가 정해지면 사라짐. 푸시는 **처음 등록할 때만**(고친 것은 메일만), 사람마다 꼬리표. 포털은 치운 알림을 기기에도 7일 기억(저장해 둔 첫 화면이 다시 보여 주지 않게).

## 4. 밝은/어두운 화면 · 기기별 배치
- 모든 페이지 머리말 왼쪽 위 **☀️/🌙** (오른쪽 ↻ 와 짝). 기기에 기억, 그리기 전에 입혀 깜빡임 없음. 밝은 유리: 바탕 · 카드 · 입력칸 · 버튼 · 탭. 페이지마다 흰 글씨를 강제한 곳은 가독성 지킴이가 진한 글씨로 자동 보정. **세션/연습 화면은 늘 어두운 화면**(무대에서 눈부심 방지).
- 찬양 허브: 📱 폰 = 한 단 카드(여백 줄임) · 📲 태블릿 세로 = 가운데 넓은 한 단 · 🖥 태블릿 가로 · 컴퓨터 = **왼쪽 붙어 다니는 옆 막대**(메뉴 · 날짜 세로 목록) + 넓은 내용. 태블릿 가로 연습 화면은 처음부터 **두 쪽 나란히**(떠 있는 도크 그대로, 끄면 기억).

- 기존: 서버 시험 전부 · 브라우저 시험 전부 다시 통과. `e2e-step11.js` 의 "다른 분 화면" 기대값 4줄은 새 방식(같은 모양 + 누르기 막기, 떠 있는 띠)으로 바꿈.
- `e2e-hub4-canvas.js` 의 "선택 도구로 바꿔도 선택 유지" 1건은 이번 작업 **전에도** 실패하던 것(그대로).

## 6. 알아 둘 점 / 한계
- 진짜 유튜브 · 제미나이 · LectServe · getBible 은 여기서 부를 수 없어 가짜 응답으로 시험했습니다. 배포 후 자막 없는 설교 하나로 "요약"을 한 번 눌러 확인해 주세요. 제미나이 영상 요약은 **공개 영상만** 됩니다(일부공개 · 비공개는 원고 붙여넣기 안내).
- 유튜브 내부 API(안드로이드 클라이언트)는 유튜브 사정으로 또 바뀔 수 있습니다 — 그때도 영상 요약으로 넘어가므로 요약은 계속됩니다.
- 밝은 화면은 공통 부품과 자동 보정으로 입혔습니다. 페이지마다 따로 칠한 특이한 부품은 조금 어색할 수 있으니 보이면 알려 주세요.
- 성능 수치는 크롬(리눅스, CPU 4배 느리게) 기준입니다. 실제 아이패드에서 날짜 전환 · 세션 시작을 한 번 확인해 주세요.
