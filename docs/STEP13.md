## 동작 (요청 항목 → 구현)
1. **코드 인식 + 좌표** — PDF 는 글자층(`getTextContent` + `convertToViewportPoint`)에서 코드와 정확한 위치(0~1 정규화 좌표)를 읽습니다. 글자층이 없는 사진/스캔은 **Tesseract.js**(v5, CDN)로 읽되, 쪽 전체가 아니라 *오선 위 띠 → 글자 덩어리마다 잘라 한 줄 모드로* 읽습니다(쪽 전체 방식은 C · G 같은 한 글자 코드를 자주 놓쳐 15개 중 7개, 덩어리 방식은 15/15 → 브라우저 시험 14개 이상 요구). `DIF#` 같은 `/` 오독은 자동 교정, 가사 · 제목은 코드로 안 봄(`Go`, `Do`, `Bad`, `Bridge`…).
2. **키 바꾸기** — 원래 조(코드 진행으로 자동 짐작, 직접 선택 가능) ➔ 목표 조 → 반음 수(가까운 방향, 예 G→Eb = −4). 목표 조에 맞춰 ♯/♭ 표기 선택, `sus4 · 6/9 · add9 · (b9) · 슬래시 베이스` 유지.
3. **덮기 + 덧그리기** — 원래 코드 글자 자리를 **종이 색으로 덮고**(악보 원본 픽셀은 그대로), 새 코드를 어두운 유리 칩 + 주황 글자로 그림. "원래 코드 그대로 보기" 로 언제든 원본 확인. OCR 이 불확실한(신뢰도 60 미만) 코드는 점선 테두리.
4. **화음(알토 빨강 `#FF4D4D` · 테너 파랑 `#4D94FF`)** — 코드 구성음 안에서 곡 전체를 함께 계산(도약 · 병행 5도/8도 · 음역 · 코드음 밖 음 벌점). 알토는 멜로디 3도 아래(높으면 위 6도), 테너는 아래 6도 · 옥타브 · 안쪽 화음음. 오선 위에 머리 표시 + 멜로디와 점선 연결(끌 수 있음). 원본 악보는 건드리지 않는 별도 캔버스.
5. **손으로 고치기** — 화음 모드: 빨강/파랑 머리를 **위아래로 끌면 오선 한 칸씩**(조표 반영) 옮겨지고 그동안 소리가 남 · 두 번 누르면 자동값 · ♭/♯ 반음 버튼 · 되돌리기 60단계. 멜로디 모드(이동/추가/지우기)와 코드 모드(고치기/추가/삭제)도 제공 — 멜로디를 고치면 화음이 다시 계산됩니다. 마우스 · 손가락 · **애플 펜슬**(포인터 이벤트) 공통, 넓게 닿은 손바닥은 무시, 수정 모드에서는 쪽 넘기기 · 확대 제스처가 덧그림 위에서 막히고 필기 도구를 고르면 자동으로 "보기"로 돌아갑니다.
6. **화음 미리듣기(Web Audio)** — 멜로디 + 알토 + 테너를 피아노 소리로. 목표 조/원래 조 선택, 성부별 켜기/끄기, 반복, BPM, 음량, 재생 중인 음 발광. 음 길이는 음표 모양(빈 머리 · 줄기 · 꼬리 · 점 · 쉼 간격)으로 짐작.
7. **저장** — 분석 결과 · 고친 화음 · 목표 키는 이 기기(`localStorage`, 키 `yn.pv.harm.<파일ID>`)에 악보별로 저장되어 다시 열면 분석 없이 바로 그려집니다. "바뀐 코드 · 화음 넣은 그림 저장" 으로 PNG 내보내기(필기 포함).

UI 는 기존 Dark Glassmorphism + 오렌지 액센트 클래스(`pv-sec`, `pv-btn2`, `pv-switch` …)를 그대로 씁니다.

## 한계 (솔직하게)
- **실제 악보 검증은 합성 악보 기준**입니다. 인쇄된 찬송가/스캔 · 사진(기울어짐 · 구겨짐 · 그림자)은 직접 확인 전이며, 기울어진 사진 보정은 없습니다. 인식이 틀리면 멜로디/코드 모드로 고치는 것이 전제입니다.
- 멜로디 인식은 **높은음자리표 · 한 줄 멜로디(리드시트)** 가정입니다. 쉼표 · 붙임줄 · 셋잇단음표 · 겹음(화음 표기)은 읽지 않고, 박자표를 읽지 않으며 음 길이는 짐작입니다. 피아노 큰 보표는 아래 줄을 "멜로디로 쓸 오선" 체크로 끕니다.
- 알토/테너는 **규칙 기반 제안**이며 정식 4성부 편곡이 아닙니다(멜로디와 코드가 맞아야 좋은 결과). 애플 펜슬 · iPad Safari 실기기 확인은 못 했고 크롬에서 포인터 이벤트를 흉내 낸 시험입니다.
- OCR 은 CDN(`cdn.jsdelivr.net`) 에서 Tesseract 를 처음 한 번 내려받아야 하므로 **인터넷이 필요**하고 오프라인 보관 목록에는 없습니다(PDF 글자층 경로는 오프라인 가능). Gemini Vision 은 구현하지 않았습니다(서버 키 · 비용 결정이 필요).
- 결과는 **내 기기에만** 저장됩니다. 팀 실시간 동기화(Socket.io)나 시트 저장에는 연결하지 않았습니다 — 필요하면 다음 단계에서 `anno` 저장/`rt.js` 와 같은 방식으로 연결할 수 있습니다.
- 같은 파일을 다른 작업이 동시에 고치고 있어(연습 화면 · 시트 · 서비스워커), 위 앵커 추가가 덮어써졌는지는 다음 작업 시작 전 `git diff` 로 확인이 필요합니다.
